# Purple AI Portfolio Website

This is a professional portfolio website with a purple theme, based on the design of antoun.me but with a complete color scheme transformation from green to purple.

## 🚀 Live Website

The website is now available at: `http://localhost:8000` (when running locally)

## Features

### 🎨 Design
- **Purple Theme**: Beautiful purple color scheme (#9b51e0 primary color)
- **Dark Mode**: Professional dark background design
- **Responsive Design**: Mobile-friendly layout that works on all devices
- **Smooth Animations**: Subtle hover effects and scroll animations

### 🚀 Functionality
- **Typing Animation**: Dynamic text animation in the header
- **Smooth Scrolling**: Navigation with smooth scroll effects
- **Interactive Elements**: Hover effects, button ripples, and animations
- **Contact Form**: Functional contact form with validation
- **Scroll to Top**: Convenient scroll-to-top button
- **Social Media Links**: Integrated social media icons

### 📱 Sections
1. **Header/Hero Section**: Introduction with typing animation
2. **About/Resume**: Personal introduction and basic info
3. **Key Facts**: Professional and personal highlights
4. **Expertise**: Technical skills and experience
5. **Certifications**: Professional certifications and achievements
6. **Extracurricular**: Additional activities and learning
7. **Teachings**: Educational courses and subjects
8. **Publications**: Research papers and publications
9. **Contact**: Contact information and form

## Usage

### Local Development
1. Clone or download the files
2. Open `index.html` in a web browser
3. Or serve using a local server:
   ```bash
   python3 -m http.server 8000
   ```
4. Visit `http://localhost:8000`

### Customization
- **Colors**: Modify CSS variables in `:root` selector in `style.css`
- **Content**: Update text content in `index.html`
- **Images**: Replace `profile-placeholder.jpg` with your own photo
- **Social Links**: Update social media URLs in the HTML
- **Contact Info**: Update email, location, and phone number
